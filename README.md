# Apples_game
Apples_Game_java
Мини игра

## Подробнее об игре
- Твоя задача это поймать как можно больше яблок!
- Ты играешь а рекорд
- Есть сохранения

## Установка
1. Если у вас есть джава:
2. Тыкните 2 раза на файл Apples_Game.jar и игра запуститься!
3. Если у вас нет джавы:
4. Откройте файл apples_game.rar
5. Распакуйте файл Apples_game.exe
6. И играйте!
